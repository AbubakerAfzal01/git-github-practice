# Day 04 - Git Branches

## What I Learned
- What a branch is and why it is used
- Creating a branch with git branch
- Switching branches with git switch
- Branches are independent - files/changes on one branch do not appear on another until merged

## Commands Practiced
- git branch
- git branch <name>
- git switch <name>

## Key Takeaway
Switching branches does not delete anything - it just changes which version of the project you are looking at. A file committed on one branch will not appear on another branch until it's merged.
