DAY 01 - GIT BASICS

1. Version control is a system that saves the history of files,
   so any previous version can be recovered later.

2. Git is a tool installed on my computer that tracks every
   change made to my project.

3. Difference between Git and GitHub: Git is a local tool that
   saves history, GitHub is an online website where that history
   is stored and shared.

4. Commands I practiced today:
   - git status
   - git add
   - git commit
   - git push
   - git pull

5. The most important thing I learned: always run git status
   before staging or committing, so I know exactly what is
   changing.

6. A real problem I faced today: my push was rejected because
   the remote already had something my local repo did not have.
   I ran git pull to merge those changes, then pushed again -
   this taught me why keeping local and remote in sync matters.
