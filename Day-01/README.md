# Day 01 — Git Fundamentals

## What I Learned

- Version Control and why it matters
- What Git is, and how it differs from GitHub
- Configuring Git identity (user.name, user.email)
- The three core areas: Working Directory, Staging Area, Local Repository
- The basic Git workflow

## Commands Practiced

git --version
git init
git status
git add <file>
git commit -m "message"

## Practical Work

Created Day-01/git-basics.txt and practiced the status → add → commit → push cycle.

## Key Takeaway

Git tracks changes in three stages — Working Directory, Staging Area, and Local Repository — and git status is the command to check that state at any point.
