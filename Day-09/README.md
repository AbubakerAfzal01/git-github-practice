# Day 09 - Git + GitHub Connection

## What I Learned
- What a remote is and what "origin" means
- Verifying the connection with git remote -v
- Upstream tracking (git branch -vv showing main tracks origin/main)
- The difference between git fetch and git pull

## Commands Practiced
- git remote -v
- git branch -vv
- git fetch

## Key Takeaway
git fetch checks for remote changes without touching my local files, while git pull fetches AND merges automatically. Upstream tracking (origin/main) is why a plain "git push" or "git pull" works without specifying the remote and branch every time.
