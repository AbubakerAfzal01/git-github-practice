# Day 03 - Undoing Changes

## What I Learned
- git restore to discard unstaged changes
- git restore --staged to unstage a file
- The difference between the two

## Commands Practiced
- git restore
- git restore --staged
- git status
- git add

## Key Takeaway
git restore --staged only unstages a file (edits stay), while git restore removes the actual edits - so unstaging and discarding are two separate steps.
