# Day 13 - GitHub Professional Features

## What I Learned
- What a Git tag is (v1.0) and how it marks a specific commit
- What a GitHub Release is, and how it builds on a tag with a title, description, and downloadable assets
- The basic concept of GitHub Actions - automating tasks with YAML workflow files

## What I Practiced
- Created and pushed a real tag (v1.0)
- Published a GitHub Release with a written changelog
- Created a simple hello.yml workflow that runs on every push
- Verified the workflow ran successfully in the Actions tab

## Key Takeaway
A tag marks a commit, a Release turns that tag into a shareable version with notes and downloadable files, and GitHub Actions can automatically run tasks (like my "Hello from GitHub Actions!" message) every time code is pushed - no manual step required.
