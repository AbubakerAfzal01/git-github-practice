DAY 12 - ISSUES + README + PROFESSIONAL REPOSITORY

1. What a GitHub Issue is used for:
A GitHub Issue is used to report a problem, suggest an idea, or keep track of a task in a repository. It helps organize the work and makes it easier to discuss things with other people.

2. What I did (creating Issue #1, closing it with a comment):
I created Issue #1 in my GitHub repository to practice how GitHub Issues work. I added a short description, then closed the issue with a comment after completing the practice.
This helped me understand how issues can be created, discussed, and closed.

3. What sections make a README "professional":
A professional README usually includes:
- Project title and short introduction
- Project overview
- Features
- Technologies used
- Project structure
- Installation or setup instructions
- How to use the project
- Examples or screenshots
- Learning or project goals
- Author information
- License, if needed

It also shows my progress through the Git and GitHub practical course, which makes the repository easier to understand and follow.
