# Day 14 - Professional GitHub Workflow

## What I Learned
- The complete professional workflow: branch, commit, push, PR, checks, merge, cleanup
- How GitHub Actions checks appear and run automatically inside a Pull Request
- Why deleting a merged branch keeps a repository clean

## What I Practiced
- Created a real feature branch (update-root-readme) and made a genuine change
- Pushed the branch and opened a real Pull Request
- Watched the Day 13 GitHub Actions workflow run as an automated check
- Merged the PR through GitHub, then synced and cleaned up locally

## Key Takeaway
A local git merge is just one command - the professional GitHub workflow is a full cycle: branch, push, PR, automated checks, review, merge, and cleanup. Each step adds visibility and safety that matters once more than one person is working on a project.
