
# Git & GitHub Practical Course

A 15-day hands-on course focused on learning Git and GitHub through practical, command-line-based exercises and real repository workflows.

This repository documents the concepts, commands, experiments, and progress completed throughout the course. Each day's work is practiced locally, documented, committed, and pushed to GitHub.

## Course Structure

| Phase | Days | Focus |
|---|---|---|
| Git Fundamentals | 01-07 | Git basics, commits, history, changes, branches, merging, and conflict resolution |
| GitHub Collaboration | 08-14 | Remote repositories, GitHub workflows, Pull Requests, Issues, and collaboration |
| Final Project | 15 | End-to-end Git and GitHub practical assessment |
