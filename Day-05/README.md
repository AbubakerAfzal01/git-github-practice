
# Day 05 - Merging & Merge Conflicts

## What I Learned
- How git merge combines changes from one branch into another
- Why merge conflicts happen when branches change the same part of a file
- How to read Git conflict markers
- How to manually resolve a conflict and complete the merge

## Commands Practiced
- git switch -c <branch>
- git branch
- git switch <branch>
- git merge <branch>
- git status
- git add
- git commit
- git push
- git log --oneline

## Key Takeaway
A merge conflict is not a Git error. It happens when Git cannot automatically decide which change to keep. I resolved the conflict manually by reviewing the changes, removing the conflict markers, combining the required content, and completing the merge.
